A free, local alternative to Wispr Flow

Updated 2026-11-22

ThunderTalk is a free, open-source dictation app for the Mac that works like Wispr Flow (press a key in any app, speak, and the text appears at the cursor) but recognizes your speech on your own Mac, with no account, no subscription and no word limit. It works offline and handles Chinese, English and mixed sentences. Wispr Flow sends audio to its cloud servers and charges $15 a month for unlimited use.

Why people look for a Wispr Flow alternative

  • Privacy. Wispr Flow processes dictation in the cloud. Its own documentation says Privacy Mode is off by default, and that turning off model improvement does not stop cloud processing. ThunderTalk's audio never leaves the Mac unless you choose a cloud engine.
  • Cost. Unlimited Wispr Flow is $15 a month. ThunderTalk is free, and its code is public.
  • Offline use. On a plane or on a locked-down network, a cloud dictation app stops working. ThunderTalk keeps working.

How fast and accurate is it?

ThunderTalk's default dictation model is ThunderTalk ASR 0.6B, its own fine-tune of Qwen3-ASR-0.6B, running in 8-bit on the Apple Silicon GPU. From the project's release notes:

  • Fewer errors: 8.0% token error rate on the standard test set, against 10.1% for the previous default model, and about 2.3× faster. A later version lowered it to 7.66%.
  • Names: on a 724-name test, names written correctly rose from 67.7% to 80.4%. Hotwords let you teach it the names and product terms it would otherwise miss.
  • Long dictations: speech is recognized while you keep talking, so across 36 dictations of 30 seconds to 4.5 minutes the wait after you stop fell from a 3.4 s median to 0.45 s.

When Wispr Flow is the better choice

Today, pick Wispr Flow if you need dictation on Windows or iPhone, or on an Intel Mac, or if you want an assistant that rewrites what you said. ThunderTalk currently runs on Apple Silicon Macs; Windows and Linux versions are planned.

How to switch

  1. Install ThunderTalk with brew install --cask realallensong/tap/thundertalk, or download it from GitHub Releases.
  2. Grant Microphone and Accessibility access when asked; the setup downloads the recommended model for your Mac.
  3. Press the hotkey (Right ⌘ by default) in any app and speak.

FAQ

Is ThunderTalk really free?

Yes. It is free for individuals, schools, non-profits and companies with fewer than 250 employees and under US$10 million in revenue, with no account, subscription or usage limit. The code is open source under the AGPL-3.0.

Does ThunderTalk send my voice to the cloud?

No, not by default. Recognition runs on your Mac. Cloud engines are optional and only used if you add your own API key.

Does it work with Chinese and English in the same sentence?

Yes. The default model is tuned for short and mixed Chinese–English dictation.

Which computers does it support?

Macs with Apple Silicon running macOS 15 or later. Windows and Linux versions are planned.
