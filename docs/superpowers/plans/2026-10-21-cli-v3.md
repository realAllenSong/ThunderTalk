# CLI v3 implementation plan

Goal: every Studio processing operation is callable headlessly by another service.
Architecture: retain cli.py's JSON-lines transport and ASR/TTS selection; add focused
media, Studio, music, and library command modules that call existing core services.
No Qt widgets except an offscreen QGuiApplication for Studio's subtitle renderer.
Spec: Task CLI3 in the task brief; baseline 933fe89 on fix/links-cli.

Constraints: worktree only; shared Python; no dependency changes; GPU/build locks;
throwaway HOME for verification; real models read only; no push; REPORT.md untracked.
Execution: autonomous, inline, with fake-based tests before implementation.

Review focus: mixed-success batches and duplicate names; cleanup on interruption;
malformed transcript/subtitle inputs; no provider/model; cross-process dictation priority;
preserved successful takes when later generation fails; machine-readable stdout.

- [x] Media: tests for URL/file input, download progress/errors/cleanup, time limits,
  batches and exports; implement source context and refactor transcribe; commit.
- [x] Studio: tests then notes, burn, speech/text translate, voices CRUD and clone
  synthesis, history CRUD/edit/export, models list/download/activate; commit.
- [x] Compose: tests then generation, warnings, lyric checks, repaint, take management,
  priority across CLI/app processes and memory errors; commit.
- [x] Interface: MCP thin wrappers, CLI version 3/capabilities, English/Chinese
  command docs and full Studio capability matrix; commit.
- [x] Verification: targeted tests, locked real runs, locked full macOS pytest,
  ruff, final review/fixes; write uncommitted REPORT.md and print it.

Rulings: --out-dir selects batch mode even for one item; each item emits a result
with item/input, followed by a summary result whose ok is false if any item failed.
History persistence is opt-in (--save-history); existing CLI v2 did not write it.
Downloads explicitly enable networking; inference stays offline. Cancellation is SIGINT.


Review ledger: independent review found and fixes covered shared ASR/TTS/translation
admission, original-input protection with trimming, preview detection with ranges,
notes failure preserving transcripts, speaker attribution, settings merge races,
MCP partial results, clone auto/best fallback and XL compatibility. Regression
tests were observed failing before the fixes. New core leases permit nested calls
within one job but reject unrelated jobs; dictation remains outside that lease.
Final verification results are recorded in the uncommitted REPORT.md.
