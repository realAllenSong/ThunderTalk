Mac 上中英混说的语音输入

更新于 2026-11-22

如果你说话时常夹着英文单词，比如"帮我把这个 bug fix 一下"，Mac 自带的听写往往要在中文和英文之间来回切换，夹在一句话里的英文很容易认错。ThunderTalk 的默认模型专门针对中英混说的短句做过微调，在你自己的 Mac 上识别，免费，也能离线用。

识别得有多准、多快

ThunderTalk 默认的听写模型是 ThunderTalk ASR 0.6B，基于 Qwen3-ASR-0.6B 微调，在 Apple 芯片的 GPU 上以 8-bit 运行。根据项目的发布说明：

  • 错得更少：在标准测试集上的 token 错误率是 8.0%，之前的默认模型是 10.1%，速度快约 2.3 倍；后续版本又降到 7.66%。
  • 人名认得更准：在 724 个人名的测试里，写对的比例从 67.7% 提高到 80.4%。热词功能可以教它认识常被认错的名字和术语。
  • 说得再久也不用等：你还在说话时它就在识别。36 段 30 秒到 4.5 分钟的听写，停下后的等待时间中位数从 3.4 秒降到 0.45 秒。

适合谁

  • 程序员和研究者：说话里全是 API、PR、模型名，热词功能能把常用术语教给它。
  • 中英双语工作的人：写邮件、写文档、和 AI 对话时，不用每说一句就切一次输入法。
  • 在意隐私的人：会议、病历、合同这类内容，声音不离开你的电脑。

怎么开始

  1. 用 brew install --cask realallensong/tap/thundertalk 安装，或者从 GitHub Releases 下载。
  2. 按提示授予麦克风和辅助功能权限，它会自动下载推荐的模型。
  3. 在设置里加几个你常说的英文术语作为热词，然后按右边的 ⌘ 开口说。

常见问题

Mac 自带的听写能中英混说吗？

可以设置多种听写语言并在听写时切换，但一句话里中英夹着说时，夹在中间的英文常常认错。

ThunderTalk 断网能用吗？

能。模型下载一次后，听写和转写都不需要联网。

怎么让它认对专有名词？

在设置里添加热词，比如产品名、人名、技术术语，它只会修改听起来像这些词的地方。
