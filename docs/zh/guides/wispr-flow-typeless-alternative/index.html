Wispr Flow 和 Typeless 的免费本地替代

更新于 2026-11-22

ThunderTalk 是免费开源的 Mac 语音输入。用法和 Wispr Flow、Typeless 一样：在任何应用里按一下快捷键说话，文字就出现在光标处。不同的是，它在你自己的 Mac 上识别语音，不用注册，不用订阅，也没有字数限制；断网也能用，中文、英文和中英混说都能识别。Wispr Flow 和 Typeless 都把声音传到云端处理，不限量使用分别要每月 15 美元和 30 美元。

为什么要找替代

  • 隐私。这两款都在云端处理语音。Wispr Flow 的文档写明，"隐私模式"默认是关闭的，而且关掉"帮助改进模型"也不会停止云端处理。ThunderTalk 默认不会把声音传出你的 Mac。
  • 价格。不限量使用每月要 15 到 30 美元。ThunderTalk 免费，代码公开。
  • 断网。在飞机上、在公司内网里，云端语音输入就用不了了，ThunderTalk 照常工作。
  • 中英混说。"把这个 PR merge 一下"这种句子，ThunderTalk 默认的模型专门为它调过。

识别得有多准、多快

ThunderTalk 默认的听写模型是 ThunderTalk ASR 0.6B，基于 Qwen3-ASR-0.6B 微调，在 Apple 芯片的 GPU 上以 8-bit 运行。根据项目的发布说明：

  • 错得更少：在标准测试集上的 token 错误率是 8.0%，之前的默认模型是 10.1%，速度快约 2.3 倍；后续版本又降到 7.66%。
  • 人名认得更准：在 724 个人名的测试里，写对的比例从 67.7% 提高到 80.4%。热词功能可以教它认识常被认错的名字和术语。
  • 说得再久也不用等：你还在说话时它就在识别。36 段 30 秒到 4.5 分钟的听写，停下后的等待时间中位数从 3.4 秒降到 0.45 秒。

什么情况下它们更合适

如果你现在就需要在 Windows 或 iPhone 上用，或者用的是 Intel 芯片的 Mac，又或者你想要一个帮你改写措辞的助手，Wispr Flow 和 Typeless 可能更适合。ThunderTalk 目前支持 Apple 芯片的 Mac，Windows 和 Linux 版本已在计划中。

怎么换过来

  1. 用 brew install --cask realallensong/tap/thundertalk 安装，或者从 GitHub Releases 下载。
  2. 按提示授予麦克风和辅助功能权限，它会自动下载适合你这台 Mac 的模型。
  3. 在任何应用里按下快捷键（默认是右边的 ⌘），开口说。

常见问题

ThunderTalk 真的免费吗？

是的。个人、学校、非营利组织，以及员工少于 250 人且年收入低于 1000 万美元的公司都免费使用，不用注册，不用订阅，没有次数限制。代码以 AGPL-3.0 开源。

我的声音会被上传吗？

默认不会，识别在你的 Mac 上完成。只有你自己接入云端引擎时，才会用到云端。

中英文夹着说能识别吗？

能。默认模型专门针对短句和中英混说做过微调。

支持哪些电脑？

目前支持 Apple 芯片的 Mac，系统为 macOS 15 或更高版本。Windows 和 Linux 版本已在计划中。
